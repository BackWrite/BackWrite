# Backwrite

> **Programmable Backend Infrastructure**

Backwrite is the programmable backend infrastructure platform combining PostgreSQL with isolated database branching, multi-tenant row-level security, high-throughput edge data APIs, and native Model Context Protocol (MCP) agent tooling.

---

### Highlights

* **Database Branching**: Spin up and tear down isolated preview and development databases in under a second.
* **Polyglot Connectivity**: Direct PostgreSQL wire on port `5432`, transaction pooler on port `6543`, and sub-millisecond Edge Data APIs over HTTPS.
* **Agent-Native Runtime**: Native MCP server (`@backwrite/mcp`) supporting Cursor, Claude Code, and Windsurf tool-calling loops with in-database vector memory (`pgvector`).
* **Zero-Knowledge & Enterprise SaaS**: Envelope AES-256 field encryption, blind index queries, and built-in transactional email plane via Stalwart Mail Server.
